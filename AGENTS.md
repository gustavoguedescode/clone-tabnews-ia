# AGENTS.md

## Sobre o Projeto
Este projeto (**clone-tabnews-ia**) é uma implementação do [TabNews](https://www.tabnews.com.br) (baseado na jornada do [curso.dev](https://curso.dev)) construída utilizando agentes de IA.

## Stack Tecnológica e Comandos
- **Framework:** Next.js utilizando o **App Router** (`app/`).
- **Biblioteca UI:** React.
- **Scripts principais:**
  - `npm run dev`: Inicia o servidor de desenvolvimento.
  - `npm run build`: Gera o build de produção.
  - `npm run start`: Inicia o servidor de produção.
